📈 用户体验趋势（2026 年主流模式）
1. 预测性 UX 从实验变标配：77% 的设计团队已采用 AI-UX 工具，AI 个性化可将任务完成速度提升 56%（Orbix Studio）。
2. 生成式 UI：模型不只输出文本，还动态选择渲染的 React 组件（Vercel AI SDK）。
3. 空白画布问题：65% 的用户无法从零写出有效提示（Nielsen Norman 2025），结构化提示模板是刚需。
4. 可见记忆管理：让用户知道 AI 记住了什么、能编辑上下文，可建立信任。
5. 流式输出 + 重生成/优化控制：8 大 LLM UX 模式中的 2 个基础模式（Designpixil 2026）。
💰 商业化趋势（2026 主流定价）
1. 单一订阅制已失效：纯订阅仅转化 2–5% 免费用户，无法覆盖重度用户算力成本（Thrad 2026）。
2. 混合定价主导：Top 50 AI 公司近半数使用 2+ 种定价模型——分级订阅 + 用量包 + 按次付费。
3. 重度用户悖论：20–30% 用户产生 10–20x 交互量，需引入「高级请求上限 + 额度充值」（Microsoft 2025 Copilot 报告）。
4. 内容变现将是增量：Notion AI 超 3000 万用户，模板/知识包市场是自然扩展方向。
5. 免费版广告：OpenAI 正在 ChatGPT 免费版测试广告，以支付 GPU 成本。

🎯 商业逻辑
  • 解决 AI 产品的不可能三角：当前的 PRO 永久 ¥9.9 定价过低，与算力成本严重错配
  • 按次付费的额度包让偶发需求用户不用升年付；重度用户升级 Ultimate+ 包可获得更多高级模型调用
  • 当前 PLUS/ULTIMATE 存储相同（300MB）无区分度，拉开存储阶梯
⚙️ 具体方案（直接对齐现有 TIER_LIMITS 改造）
  • FREE 配额微调：50MB / 200轮 不变 → 新增「免费版广告」M6
  • PRO 永久：100MB / 2000轮（+1000轮）/ 可分享 → 定价维持 ¥9.9 吸引转化
  • PLUS 年付 ¥39 / 永久 ¥129：500MB / 无限 / API 100/min + 额度包 500 AI 积分/月
  • ULTIMATE 年付 ¥149 / 永久 ¥399：2GB / 无限 / API 500/min + 2000 AI 积分/月 + 专属模型路由
  • 新增 AI 积分系统（Quota）：摘要、导出、AI 整理等增值操作消耗积分；余额不足单独购买充值包（¥9.9/500分、¥29/2000分、¥99/10000分）

06
风险识别与缓释策略
提前识别 AI 项目常见的成本/合规/信任三类风险
⚠️ 风险 1：AI 调用成本失控
场景：摘要 / 整理 / 导出等 AI Agent 操作如果免费放开，可能被脚本滥用，算力账单飙升。
缓释： · 所有 AI 增值操作走积分体系（M4），消耗即扣费，余额不足拒绝
· PLUS/ULTIMATE 赠送的月积分设上限，超出必须买充值包
· 后端 per-user per-minute 限流（复用现有 express-rate-limit 模式）
· 模型路由：非核心任务走 deepseek-chat（更便宜），核心润色才走 reasoner
· 每月成本监控 + 告警阈值（月算力成本超月营收 X% 触发降级策略）
⚠️ 风险 2：AI 幻觉 / 摘要错误
场景：AI 摘要丢失关键信息，用户基于错误摘要决策 → 信任危机。
缓释： · 所有摘要卡片上显式标注「AI 生成，建议核对原文」+ 一键跳转对应对话位置
· 摘要卡片显示置信度分数；低分自动标黄 + 建议用户复核
· 提供「反馈此摘要」按钮（👍/👎），收集反馈数据用于后续 prompt 优化
· 导出前必须提示用户「已由 AI 润色，请审阅后使用」并勾选同意
⚠️ 风险 3：广告干扰用户流失
场景：FREE 版搜索结果中植入广告 → 部分用户感到被打扰而卸载。
缓释： · 先 A/B：只对 20% 随机分组灰度，对比留存/转化差异，显著差则停
· 严格限制频次：每日 ≤20 次展示，同一搜索只出 1 条原生卡片，绝不做弹窗/插屏
· 广告素材必须审核，过滤竞品与低俗
· 搜索页顶部 banner 常驻「升级 PRO ¥9.9 永久去广告」提示，把「反感」转化为「付费动机」
⚠️ 风险 4：市场 UGC 质量与合规
场景：用户上架违规/低质模板 → 平台声誉受损 + 合规风险。
缓释： · 所有上架必须走人工审核（Admin 后台的「市场审核」），不允许自动发布
· PLUS 限 5 个 / ULTIMATE 无限的数量门槛，降低审核量
· 举报机制：用户可举报 listing，+3 次举报自动下架待复审
· 创作者协议 + 知识产权条款内嵌，平台保留下架追责权利
· 销售额排名 + AI 质量分双重排序，避免低质 listing 占曝光
